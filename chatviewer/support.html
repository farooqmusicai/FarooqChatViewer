What to include

  • App version, visible in Help & privacy (this guide covers 2.0.3).
  • Your Windows version and whether you installed from the Store, Setup or a portable package.
  • The steps taken, expected result and actual result, including any error text.
  • Whether you opened a folder or imported a ZIP; approximate archive size and export source, if relevant.
  • A screenshot with names, phone numbers, messages and filenames redacted, if it helps.

Do not send passwords, verification codes or complete private chat archives. If a sample is necessary, create a small fictional conversation that reproduces the issue. Support messages are handled as described in the privacy policy.

Common questions

No conversations appear after opening a folder

Check that each chat has a readable text transcript alongside its media. Open the individual chat folder to narrow the issue. A WhatsApp encrypted backup is different from an exported text conversation. Check any parsing warnings.

A photo, video or voice note is missing

Confirm that WhatsApp included the attachment and that its original filename is unchanged. Keep it with the transcript, and download online-only cloud files. Missing export content cannot be recovered by the viewer.

A video will not play or has no thumbnail

Try opening the same saved file in a compatible local player. Media and thumbnail support can vary by machine and format. Report the extension and error without sending private media.

Dates look wrong

Review the date-order setting in the chat header. An ambiguous date such as 06/07 can mean June 7 or July 6. Use the original export and a date with a day greater than 12 to choose the right interpretation.

A share destination is unavailable

Windows controls which compatible installed apps appear. Check that the destination app is installed and configured. Use Copy or Save where available, then complete sending in that app. Test a fictional message first.

My remembered library is unavailable

Reconnect the drive or make the cloud folder available locally. Select the folder again if it moved. Disconnect folder only clears the remembered connection; your archive remains on disk.

A large archive is slow or a ZIP is rejected

Full-text indexing uses memory. Try a smaller folder to isolate the issue and allow scanning to finish. ZIP import applies size, file-count and path checks; ensure adequate disk space or extract a trusted ZIP with Windows and open its folder.

Does it connect to my WhatsApp account?

No. It reads exported files you select. It does not synchronize live conversations, recover omitted content, or restore exports to WhatsApp.
