# Changelog

## 2.0.3 — 8 September 2026

- Search full indexed user-message content from the left panel with normalized whitespace/case and navigation to older matches.
- Restore the selected parent folder at startup until explicitly disconnected or replaced.
- Classify recognized WhatsApp notices as centered system records and exclude them from user-message counts, previews, dates and search.
- 22 automated tests pass; Windows test packages built. Owner testing continues for 1–2 days.
- Expanded repository documentation and added a maintainer handoff and owner testing checklist; runtime version unchanged.

## 2.0.2 — 8 September 2026

- Improved media previews, name initials and visible search results.
- Repaired voice play/pause/resume state when subscribing to an already-playing player.
- 19 automated tests passed.

## 2.0.1 — 8 September 2026

- Fixed Windows sharing preparation freeze and native payload lifetime.
- Added more chat-like photo, sticker, voice, video and link cards with explicit online previews.
- Added local asynchronous Windows thumbnail/duration lookup.
- 16 automated tests passed, plus native sharing and media diagnostics with documented limits.

## 2.0.0 — initial Windows test implementation

- Implemented folder/ZIP archives, parsing, themes, search, media and Windows packaging.
- Opened chats at the latest message, cleaned export name prefixes and exposed share actions.
- Initial 12-test suite and local executable inspection completed.

These entries describe local development/test builds. They do not imply that public GitHub binary releases or Store submissions were published for these versions.
