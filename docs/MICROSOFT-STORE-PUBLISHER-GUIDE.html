5. Copy the English listing text

The same values are supplied in store-listing.json for reuse.

Short description

Read exported WhatsApp chats and saved media on your Windows PC.

Description

Farooq Chat Viewer lets you read exported WhatsApp conversations and their saved media on your Windows PC.

Open a folder of chat exports or import a ZIP, browse dated messages, and search conversation names and message text. View saved photos and stickers, play voice notes and supported videos, and open documents with compatible installed applications.

Your selected library is remembered when you reopen the app. Choose your name under Me, adjust ambiguous numeric dates, and select a light, dark or system theme. English is the primary interface language; Urdu and Arabic translations are partial with English fallback.

Normal reading and search happen locally. There is no WhatsApp login, app account, automatic archive upload or app analytics service. Optional online previews contact the linked website only when selected. Opening links and sharing involve your browser, Windows or another application.

The viewer displays only the content included in your export. It does not synchronize live conversations, recover omitted or deleted messages, decrypt account backups, or restore exports to WhatsApp. Keep an independent copy of important files. Media playback and available share destinations depend on your Windows installation and installed applications.

Independent software by Mohammad Farooq. Not affiliated with or endorsed by WhatsApp or Meta.

8. Notes for certification

This is a Flutter Win32 desktop reader for user-selected exported chat files. No account, password or WhatsApp sign-in is required. It does not send live messages or connect to a WhatsApp account.

Testing: create a local folder, extract the supplied fictional reviewer-sample.zip into it, open that folder in the app and select Project notes. Search for picnic, choose Me as your sender, and test the sample image/audio with the available controls. Close/reopen to test folder restoration. Disconnect folder clears the remembered connection only. Copy/save can be tested with the fictional files. Sharing requires a compatible destination application and is completed by the tester in that application.

runFullTrust is required for the existing Win32 Flutter process, user-selected filesystem access, local native media playback and Windows sharing integration. The app runs in the user's session and does not install a service or request administrator elevation. internetClient is used for optional online link previews. No broadFileSystemAccess capability is declared.

The attached privacy URL describes local processing and optional external actions. The app includes local Help & privacy information. Only publish after the owner has verified the packaged app and the live policy pages.
